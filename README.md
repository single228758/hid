# HidreamAI 图像生成插件

## 插件简介

HidreamAI插件(`hid`)是一个基于dow框架的插件，用于连接HidreamAI图像生成服务，让你可以直接在聊天中使用AI生成精美图片。通过微信扫码登录，轻松享受HidreamAI的强大文生图功能。

## 功能特点

- 微信扫码登录HidreamAI服务
- 支持多种图像生成比例(16:9, 9:16, 4:3, 3:4, 1:1)
- 支持提示词优化润色
- 支持反向提示词(negative prompt)
- 自动刷新登录令牌，保持登录状态
- 生成高质量AI艺术图像

## 依赖项

本插件需要以下Python库：

```
requests>=2.28.0
Pillow>=9.0.0
python-dateutil>=2.8.0
```

## 安装方法

### 方法一：手动安装

1. 确保已经安装并配置好dow框架
2. 在`plugins`目录下创建`hid`文件夹
3. 将插件文件复制到`hid`文件夹中
4. 安装依赖：
   ```bash
   pip install requests Pillow python-dateutil
   ```
5. 重启chatgpt-on-wechat服务

### 方法二：使用插件管理器安装

如果你已经启用了`godcmd`插件，可以使用以下命令安装：

```
#installp hid
```

安装完成后，需要执行`#scanp`命令或重启服务使插件生效。

## 使用方法

### 登录

首次使用需要登录HidreamAI服务：

```
h 登录
```

或

```
h login
```
![26801](https://github.com/user-attachments/assets/545684ea-f140-41db-9a82-f4d3a83f1d0e)

系统将显示微信二维码，使用微信扫码后在手机上确认登录。

### 登出

如需退出登录：

```
h 登出
```

或

```
h logout
```

### 生成图片

基本命令格式：

```
h 提示词-图像比例-润色<反向提示词
```

各参数说明：
- 提示词：描述你想要生成的图像内容(必填)
- 图像比例：可选值为 16:9、9:16、4:3、3:4、1:1，默认为16:9
- 润色：添加"润色"关键字后，系统会自动优化你的提示词
- 反向提示词：在"<"符号后添加不希望出现在图像中的元素

示例：

1. 最简单的使用方式，生成默认16:9比例的图像：
   ```
   h 一只可爱的柴犬
   ```

2. 指定图像比例：
   ```
   h 一只可爱的柴犬-4:3
   ```

3. 使用提示词润色功能：
   ```
   h 一只可爱的柴犬-16:9-润色
   ```

4. 添加反向提示词（避免出现模糊、畸形等问题）：
   ```
   h 一只可爱的柴犬-1:1<模糊,畸形,低质量
   ```

5. 完整使用所有参数：
   ```
   h 一只可爱的柴犬-9:16-润色<模糊,低质量,畸形
   ```

## 配置文件

插件会在`plugins/hid`目录下自动创建`config.json`配置文件，用于存储登录信息。配置文件中包含以下关键信息：

- cookies：存储服务器会话信息
- refresh_token：用于刷新访问令牌
- user_id：用户ID
- device_id：设备标识
- expire_time：登录过期时间
- username：用户名
- nickname：用户昵称

**注意**：请勿手动修改配置文件，以免导致登录异常。

## 注意事项

1. 插件依赖微信扫码登录，确保你的微信账号已绑定HidreamAI服务
2. 登录状态会自动保持，但如果长时间未使用，可能需要重新登录
3. 图片生成可能需要一定时间，请耐心等待
4. 生成图片质量受到提示词质量的影响，建议使用润色功能优化提示词

## 常见问题

1. **登录失败或超时**
   - 确保网络连接稳定
   - 检查微信扫码是否正确完成
   - 尝试重新执行登录命令

2. **生成图片失败**
   - 检查是否已登录
   - 确认提示词格式正确
   - 尝试使用更简单的提示词

3. **插件无响应**
   - 检查日志文件中是否有错误信息
   - 重启dow服务
